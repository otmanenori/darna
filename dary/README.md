# داري

واجهة عربية متجاوبة لسوق تجريبي للمأكولات المنزلية في طانطان. صور `assets/food/` هي الصور التي أرسلها المستخدم، مرتبة حسب الحلويات والوجبات الرئيسية والفطور. الصور التجريبية السابقة ما زالت مستخدمة في مشهد الصفحة الرئيسية.

## التشغيل

- `npm run dev` يشغّل المعاينة على http://localhost:4173
- `npm test` يشغّل اختبارات البحث والتصفية ومجموع السلة.
- `npm run build` ينسخ الموقع الثابت إلى `dist/`.

لا يحتاج المشروع إلى تثبيت حزم خارجية. السلة والمفضلة تُحفظان محلياً في المتصفح. البحث والفرز والتصفية والنوافذ واللوحات تعمل محلياً، بينما تسجيل الدخول والطلب وربط البائعين والتوصيل غير متصل بخدمات فعلية.

أسماء المطابخ والأسعار والبيانات في النسخة الحالية أمثلة تصميمية. ينبغي استبدالها ببيانات مؤكدة وصور أصحاب المنتجات قبل أي إطلاق. هذا المشروع غير منشور على الإنترنت.
